# サーキットシミュレーター

単一コーナーで5つの走行ライン（アウトインアウト／レイトエイペックス／アーリーエイペックス／インベタ／自分のライン）を物理モデルで比較し、区間速度・タイム差・G-G図・4輪荷重を表示する。車種プリセット: GRB（既定）/GR86/ND/FL5/GRヤリス

2つのページがある。

| ページ | 何をするか |
|---|---|
| `index.html`（1コーナーモード） | 半径・角度・幅などを自分で決めた1つのコーナーで、5本のラインを比べる |
| `section.html`（区間モード） | 地図で実在の道の区間をなぞり、複数コーナーを通しで走るラインを比べる |

## 区間モードでできること
- 地図（OpenStreetMap／国土地理院の航空写真）に始点・終点・経由点を置くと、道路に沿った経路を取り、曲率からコーナーを自動で検出する
- 6本のライン（中央／全アウトインアウト／全レイトエイペックス／全インベタ／自分のライン／最速）を同じ条件で走らせ、コーナーごとの最低速度と通過タイム、速度グラフ、中央とのタイム差、G-G図、4輪荷重を見る
- 「最速」は条件が変わるたびに自動で探し直す（探索中は進捗を表示。条件を変えると中止して再開）
- コーナーを選んで「自分のライン」（エイペックスの位置・内への寄せ・入口で外に居続ける距離）を調整し、最速との差を見る
- 位置スクラブ・再生で、地図の車・グラフの縦線・荷重カードを連動させる
- 道幅を OSM のタグから提案（「適用」ボタンで入れる）したり、航空写真で道の端を2点クリックして測れる。全幅／片側のみの切り替えもある
- 区間（点・幅・進入速度・車種・自分のライン）を名前をつけてこのブラウザに保存できる
- 画面は「夜の峠」のデザイン（黄＝最速・差がつく所、青＝自分のライン、赤＝遅くなる所。中央と型ラインは灰色の線種違い）。ヘッダーの「昼」「夜」で明るい版に切り替えられる
- コーナー表の「1コーナーで詳しく」で、そのコーナーの半径・角度・幅・入口速度を引き継いで `index.html` を新しいタブで開く

### 使い方の流れ
1. 地図をスクロール／拡大して目的の道を出し、「始点」「終点」（必要なら「経由点」）を押して地図をクリックする
2. 道幅を確認する（OSM の値があれば知らせるので、使うなら「適用」。違えば「測る」か、スライダーで直す）。進入速度と車種を選ぶ
3. 判定カード・コーナー表・グラフで、中央ラインと最速ラインを比べる。行を押すとそのコーナーに地図が寄る
4. コーナーを選んで「自分のライン」を動かし、タイムの差を見る
5. 名前をつけて保存する（次回は「保存した区間」から開く）。気になったコーナーは「1コーナーで詳しく」へ

経路が3回続けて取れないときは「手動で道をなぞる」で、道の上を数点クリックして線を引ける。

- ローカル:
  - `index.html` はファイルをそのままブラウザで開ける
  - `section.html` と `test.html` は **http で開く**。地図タイル・経路 API（OSRM）・道幅 API（Overpass）への通信や、テストファイルの取得が `file://` だと動かないため。例:
    ```
    npx -y http-server -p 8765
    ```
    を、このフォルダ（またはその親）で実行し、`http://localhost:8765/section.html` を開く
- 区間モードはネットワークが必要（地図・経路取得）。ビルドは無く、Leaflet は CDN から読む

## テスト
- `npm test`（Node 21 以上（確認は 24）。`node --test` にファイルの glob を渡すため）: `test/*.test.js` を `node --test` で実行する
- `test.html` をブラウザで開く（http で）: 同じテストをブラウザで走らせ、✅／❌と合計を表示する。`test/physics.test.js`（`index.html` のエンジン部をファイルとして読む回帰テスト）だけは Node（`npm test`）でのみ走る
- 切り出し前に記録した区間タイムを取り直すときは `test/regress-record.js`（物理計算を意図して変えたときだけ）

## ファイル
- `index.html` — 1コーナーモード（計算エンジン＋画面。単一HTML）
- `section.html` — 区間モードの画面（HTML と CSS）
- `css/theme.css` — 両ページ共通の見た目「夜の峠」（色・書体・ボタン・面・黄色い板・ひし形の標識）。夜／昼の2組の色を持つ
- `js/header.js` — ヘッダー帯の昼／夜の切替（既定は端末の設定、選んだら localStorage `circuit-sim-theme` に保存）と、スマホでスクロールしたときの縮小
- `js/physics.js` — 車両モデルと走行シミュレーション（`index.html` のエンジン部から切り出したもの）
- `js/track.js` — 緯度経度 → 中心線・法線・曲率、コーナー検出、走行範囲
- `js/lines.js` — 走行ラインの生成（中央・アウトインアウト・レイト・インベタ・自分のライン）と最速の探索
- `js/map.js` — 地図（Leaflet）まわり、経路取得（OSRM）、道幅取得（Overpass）、手動のなぞり線
- `js/store.js` — 区間の保存（localStorage）
- `js/section-render.js` — 判定・表・グラフ・G-G図・荷重カードの HTML/SVG を作る部品（DOM に触らない）
- `js/section-ui.js` — `section.html` の状態管理とイベントの配線
- `test/` — 自動テストと、その共有部品（`harness.js`・`fixtures/`）
- `test.html` — ブラウザ用のテスト実行ページ
- `docs/仕様.md` — 何を作るか（設計の記録）
- `docs/計画_区間モード.md` — 区間モードの実装計画
- `docs/状況.md` — 今どこまで・次に何を
