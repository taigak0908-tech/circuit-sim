# 仕様

## 目的（1行）
峠などの実在の道を地図でなぞって「区間」を作り、複数コーナーを通しで走行ラインを比べて、どこで何秒差がつくかを物理モデルで見る。単一コーナー比較（既存）はそのまま残す。

## 誰のため・何のため
- 本人が自分の走りを速くするため（主）。走っているのは特定のサーキットではなく峠区間
- 走行理論の理解・実験のため（副）
- 実走ログは取っていない。ログ記録機能（B案）は **2026-10-05 に見送り**（あとで欄に残す）

## 今できること（既存 `index.html`、変更しない）
単一コーナーで5本の走行ライン（アウトインアウト／レイトエイペックス／アーリーエイペックス／インベタ／自分のライン）を比較し、区間速度・タイム差・G-G図・4輪荷重を表示。車種プリセット: GRB（既定）/GR86/ND/FL5/GRヤリス。

## 区間モード（新規 `section.html`）

### 1. 全体の形

ページは2つ。上部タブで行き来する。
- `index.html` — 1コーナー比較（既存。壊さない）
- `section.html` — 区間モード（新規）

コードは5ファイルに分ける。ビルド不要、`<script>` で読む。

| ファイル | 役割 | 由来 |
|---|---|---|
| `js/physics.js` | 車のモデル・タイヤ限界・速度計算（前後進パス）・4輪荷重 | `index.html` から切り出し。両ページ共用 |
| `js/map.js` | 地図表示・始点終点クリック・道路沿いの線の取得・幅の計測・区間の保存 | 新規 |
| `js/track.js` | 座標列 → 1m刻み中心線・曲率・コーナー検出・走行範囲 | 新規 |
| `js/lines.js` | ラインソルバー（既存の最小曲率ソルバーを移植）・型ライン・自分のライン・最速探索 | 既存を一般化 |
| `js/section-ui.js` | 区間モードの画面（表・グラフ・スクラブ・地図上のライン描画） | 既存の描画を流用 |

外部ライブラリ・サービス（すべて無料・鍵不要）
- Leaflet（CDN）— 地図表示
- OpenStreetMap タイル — 地図
- 国土地理院 航空写真タイル — 幅の計測用
- OSRM 公開サーバー（`router.project-osrm.org`、driving プロファイル、`overview=full&geometries=geojson`）— 始点→終点の道路沿いの座標列

切り出しの安全策: `physics.js` を切り出す**前**に、既存ページで5車種×3コーナー種のタイム（15個）を記録し、切り出し後に同じ数字（誤差0.001秒）が出ることを確認する。

データの流れ: 地図クリック → OSRM → 中心線と曲率（track）→ ライン生成（lines）→ 速度計算（physics）→ 表・グラフ・地図に描く（ui）。スライダー変更時は「ライン生成」以降だけやり直す。

### 2. 区間の作成（地図）

操作の流れ
1. 地図を開く。前回表示位置を記憶（初回は日本全体）。地名検索は付けない
2. 「始点」→道路をクリック、「終点」→道路をクリック。OSRM が道路沿いの線を返し、地図上に描く
3. 経路が別の道を通ったら「経由点」を追加クリック（最大5つ）。経由点を通るよう再取得
4. 幅の計測: 「航空写真」に切り替え → 「幅を測る」→ 道の左端・右端をクリック → 距離(m)が幅スライダーに入る。何度でも測り直せる
5. 走行範囲の切り替え: 「全幅」／「自車線のみ」。自車線は左側通行で進行方向の**左半分**
6. 「区間を保存」: 名前を付けてブラウザのローカル保存（localStorage）。一覧から呼び出し・削除

幅
- 区間全体で1本のスライダー。既定 6.0m、範囲 3〜12m
- OSM に `width` があればそれを、無くて `lanes` があれば `lanes×3m` を初期値にする。どちらも無ければ 6.0m
- 途中で幅が変わる区間は対象外（あとで）

進入速度: 区間先頭の速度をスライダーで指定（既定 60km/h）。終端は制限なし（ゴールまで全開）

保存する内容: 名前、始点・終点・経由点の座標、幅、走行範囲、進入速度、車種、自分のラインの設定（コーナーごと）、保存時の区間長。経路の座標列は保存せず、開くたびに取り直す。区間長が保存時と5%以上違えば「道路データが変わっています」と注意して続行

区間長の制限: 100m〜5km。範囲外は注意を出して計算しない

取れないもの: 道幅（上記で補う）、高低差、バンク。高低差は国土地理院の標高タイルで足せるので、`track.js` の中心線に `z` を持てる形にはしておく（計算には使わない）

### 3. コーナー検出とライン生成

コーナー検出（`track.js`）
- OSRM の座標列を平面座標（区間の中心を原点とするメートル座標）に変換し、1m刻みに補間。移動平均（窓 ±5m）で滑らかにしてから曲率 κ(s) を出す
- |κ| > 1/150（R=150m 相当）が 8m 以上続いたら1つのコーナー。保持する値: 番号、向き（左／右）、最小R、曲がり角度、開始・終了位置(s)
- 間が 15m 未満の同方向コーナーは1つにまとめる（複合コーナー）
- 地図上に「①右R38 90°」の形で番号表示。表・自分のライン調整はこの番号で指す

ライン（6本）。すべて既存の「幅内で曲率最小・ピン（必ず通る点）付き」ソルバーで、ピンの置き方だけ変える。

| ライン | ピンの置き方 |
|---|---|
| 中央 | 中心線そのまま（比較の基準、タイム差0） |
| 全アウトインアウト | ピン無し。幅内で曲率最小の線 |
| 全レイトエイペックス | 各コーナーの 65% 地点を内側いっぱいに。手前は外側を保持（既存の delay=10m 相当） |
| 全インベタ | コーナー内は内側いっぱいに固定。コーナー間は曲率最小でつなぐ |
| 自分のライン | コーナーごとに「エイペックス位置(%)」「内側への寄せ(0〜100%)」「外側を保つ距離(m)」を調整。初期値は最速の結果 |
| 最速 | 「自分のライン」と同じ3値をコーナーごとに自動探索 |

最速探索（`lines.js`）
- コーナーを順に1つずつ、他を固定して「位置 7段 × 寄せ 3段 × 保持 3段 = 63通り」を試し、区間タイム最短を採用。全コーナーを2周
- 探索中は進捗バーを出し、他の5本を先に表示。探索中に条件が変わったら中止して新条件でやり直す

S字の扱い: ピンの座標を「道の左右」で持ち、コーナーの向きで内外に変換する。ソルバーが間を滑らかにつなぐ

走行範囲: 「全幅」は中心±(幅/2 − 余白1.0m)。「自車線」は左端+余白 〜 中心。既存の対称な `b` を上下非対称 `[bLo, bHi]` に広げる

### 4. 画面と表示

レイアウト（PC前提、スマホは縦積み）
- 左: 設定パネル（車種、区間の保存一覧、幅、走行範囲、進入速度、自分のライン調整）。既存の車種・自分のライン部品を流用
- 右上: 地図。道路線・コーナー番号・選択ラインを色付きで重ねる。航空写真切り替え。スクラブに連動して車の点が動く
- 右下: 表とグラフ

判定カード: 「最速は中央より −2.84秒。差が最も大きいのは ③左R22（−0.61秒、旋回）」のように、一番効くコーナーを1文で言う

コーナー表: 行＝コーナー、列＝各ラインの「最低速度 km/h」「そのコーナーの通過タイム」。凡例でライン表示切替。行クリックでそのコーナーを地図で拡大し、自分のライン調整スライダーをそのコーナー用に切り替える

グラフ（横軸は区間の距離 m、コーナー区間に薄い帯と番号）
- 速度 vs 距離
- 中央とのタイム差の積み上げ vs 距離
- G-G図・4輪荷重カード（既存のまま、スクラブ位置の値）

位置スクラブ: 既存と同じ。地図の車の点・グラフ縦線・荷重カードが連動。再生ボタンあり

地図上のライン: 既定表示は「中央」「最速」「自分」の3本。凡例で切替。選択中のラインだけ太く描く

1コーナーページとの行き来: 上部タブ。コーナー表の各行に「1コーナーモードで詳しく見る」ボタン。R・角度・幅・進入速度を URL パラメータで `index.html` に渡す（`index.html` 側は受け取りの小改修のみ）

### 5. エラー処理

すべて画面上部に日本語1行で出し、アプリは止めない。
- OSRM 失敗（オフライン・混雑）: 「経路を取れませんでした」＋再試行ボタン。3回失敗で**手動モード**（道路上を数点クリックして線を引く。滑らかに補間）に切替可
- 始点終点がつながらない: 「道路としてつながっていません。経由点を足すか始点を少しずらしてください」
- タイル読込失敗: 地図は空白でも計算と表は動く
- 区間長が範囲外: 注意を出して計算しない
- コーナー0個: 「ほぼ直線です」。速度・タイムだけ表示
- 保存区間の長さが5%以上変化: 注意して続行
- 探索中の条件変更: 中止して再開

### 6. テスト

自動（`test.html` をブラウザで開く。依存なし）
- `track.js`: 半径Rの円弧 → 曲率 1/R（誤差2%以内）。S字 → 左右2コーナー検出。ノイズ(±1m)を乗せても検出結果が同じ
- `lines.js`: 全ラインが走行範囲内。インベタは全コーナーで内側いっぱい。最速のタイム ≤ 他の5本
- `physics.js`: 切り出し前に記録した15個のタイムと一致（誤差0.001秒）

手動（テスト担当）: 実在の峠を1つ選び、始点終点 → 表示 → 幅計測 → 保存 → 読み込み → 1コーナーモード引き継ぎ を一通り
